# Source library index

Use this index before substantial copywriting work. It preserves the examples and lessons collected for this skill so the craft references do not flatten the masters into generic advice.

## Provenance labels

- **Verbatim exemplar** means the displayed headline or short passage preserves the source wording. Typography and punctuation may follow the clearest available transcription.
- **Documented case** means the underlying campaign, test, or technique is historical, while the description is a concise summary.
- **Transfer example** means new copy created during the research to demonstrate how a principle moves into a modern context. It is not a quotation or historical control.

Never blur these labels. If a transcription is uncertain, consult the linked scan or edition instead of guessing.

## Useful combinations

- **Headline or short ad:** Ogilvy + Schwartz, or Whitman + Hopkins.
- **Landing page or sales letter:** Schwartz + Sugarman + Hopkins.
- **Product page:** Ogilvy + Hopkins; add Sugarman when story and objections carry the sale.
- **Cold social or native ad:** Schwartz + Sugarman; add Brunson for destination and follow-up continuity.
- **Email sequence:** Sugarman + Brunson; add Schwartz when awareness changes across the sequence.
- **Offer or funnel diagnosis:** Hopkins + Brunson; add Schwartz for market and message diagnosis.
- **Brand-response campaign:** Ogilvy + Hopkins so immediate response does not erode durable positioning.

## How to use an exemplar

1. Read the exact line in context and identify what the prospect already knows.
2. Name the line's real job: select, promise, dramatize, explain, prove, reframe, or advance.
3. Mark the product fact or market desire that makes the wording credible.
4. Observe the language mechanics: length, rhythm, punctuation, number, image, contrast, and information order.
5. Rebuild the decision from the user's evidence. Do not produce a close imitation or reuse a famous phrase as a template.
6. Check the transfer against [eval.md](eval.md). A historically successful structure cannot rescue an unsupported modern claim.

The library is a set of controls to think against. It is not a bag of phrases to remix.
